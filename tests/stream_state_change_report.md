# Stream State Change Report

Each section shows the quiescent board frames selected for further analysis from the raw ESP32 camera stream. The detector localizes the board once, warps every frame, computes frame-to-frame board deltas, and groups the stream into quiet runs only. Every run of at least one quiet pair becomes a quiescent segment, and consecutive segments define the brackets for later analysis. There is no additional motion acceptance criterion in this phase.
